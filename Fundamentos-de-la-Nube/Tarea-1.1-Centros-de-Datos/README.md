## Objetivo

Investigar un centro de datos situado en España a partir de DataCenterMap y la web de la empresa, y redactar un informe con sus características.

## Centro elegido

**Templus Valencia VAL01**, en el Parque Tecnológico de Paterna (C/ Louis Pasteur, 6).

| Apartado | Resumen |
|:--|:--|
| Tipo | Colocation neutral, centro regional |
| Capacidad | 400 m² de salas IT, unos 85 racks, 0,6 MW, de 2 a 12 kW por rack |
| Fiabilidad | Tier III (mantenimiento concurrente) |
| Certificaciones | ISO 27001, ISO 9001, ISO 50001, ENS Alto |
| Conectividad | Aire Networks, Axarnet, CLDIN, Cogent y red paneuropea de Templus |
| Medio ambiente | 100 % renovable, planta fotovoltaica, circuito cerrado de agua |

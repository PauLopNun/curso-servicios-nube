=== 4. Receptor sns_configs con el ARN del tema ===
[ec2-user@172-31-23-210]$ sudo chown -R alertmanager:alertmanager /etc/alertmanager /var/lib/alertmanager
[ec2-user@172-31-23-210]$ cat /etc/alertmanager/alertmanager.yml
# Alertmanager: todas las alertas van al tema SNS, que las reenvía por correo
route:
  receiver: correo-sns
  group_by: ['alertname', 'instance']   # un correo por alerta e instancia
  group_wait: 10s
  group_interval: 1m
  repeat_interval: 1h

receivers:
  - name: correo-sns
    sns_configs:
      - topic_arn: arn:aws:sns:us-east-1:381492287993:alertas-prometheus
        sigv4:
          region: us-east-1
        send_resolved: true
        subject: '[{{ .Status | toUpper }}] {{ .CommonLabels.alertname }} - {{ .CommonLabels.severity }} - {{ .CommonLabels.nombre }}'
        message: |
          {{ range .Alerts }}Alerta: {{ .Labels.alertname }}
          Estado: {{ .Status }}
          Severidad: {{ .Labels.severity }}
          Instancia: {{ .Labels.instance }} ({{ .Labels.nombre }}, {{ .Labels.instance_id }})
          Resumen: {{ .Annotations.summary }}
          Detalle: {{ .Annotations.description }}
          Desde: {{ .StartsAt }}
          {{ end }}

=== 5. Bloque alerting en prometheus.yml (localhost:9093) ===
[ec2-user@172-31-23-210]$ cat /etc/prometheus/prometheus.yml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

alerting:
  alertmanagers:
    - static_configs:
        - targets: ['localhost:9093']

rule_files:
  - /etc/prometheus/alert.rules.yml

scrape_configs:
  - job_name: 'node_exporter'
    ec2_sd_configs:
      - region: us-east-1
        port: 9100
        filters:
          - name: tag:Monitorizar
            values: ['prometheus']
    # Etiquetas extra a partir de los metadatos de EC2, para reconocer cada nodo
    relabel_configs:
      - source_labels: [__meta_ec2_tag_Name]
        target_label: nombre
      - source_labels: [__meta_ec2_instance_id]
        target_label: instance_id

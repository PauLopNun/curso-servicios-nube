# Práctica 1: CI/CD con GitHub Actions

- Curso: Despliegue de servicios administrados en la nube
- Documento original: [`material/enunciado-cicd-github-actions-s3.pdf`](material/enunciado-cicd-github-actions-s3.pdf)

## Partes

1. Herramientas: cuentas de GitHub y Notion, y configuración inicial de Git
2. Fase 1: página de login en HTML, CSS y JavaScript con validación en el cliente (se parte de los ficheros proporcionados)
3. Fase 2: repositorio `login-app-cicd`, primer commit y GitFlow simplificado (`main`, `develop`, `feature/*` y `fix/*`)
4. Fase 3: workflow de CI en `.github/workflows/ci.yml` con validación de HTML, linting y tests
5. Tarea final: copia automática de los archivos a un bucket de Amazon S3 con GitHub Actions, guardando las credenciales en los Secrets del repositorio

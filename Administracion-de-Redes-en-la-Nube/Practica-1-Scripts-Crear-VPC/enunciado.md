# Práctica 1: creación de redes con scripts

- Curso: Administración de redes en la nube
- Documento original: `aws2_10.pdf`, "Práctica 1. Creación de redes públicas"

## Qué se pide

- Un script `.sh` y otro de Boto3 que creen una VPC, una subred y un EC2.
- La ejecución reflejada en el panel de control, con muy poca explicación.
- Responder a las preguntas, entre ellas: ¿podemos tener conexión desde el exterior con el EC2?

La tabla de enrutamiento y la eliminación quedan para otra práctica.
